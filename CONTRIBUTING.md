# Contributing

Issues and contributions in Russian, English or Spanish are welcome. Describe the actual file contents, requested target, macOS version and reproducible steps. Do not attach private media or logs containing private paths; create a disposable fixture instead.

Build and test with the commands in README.en.md. Conversions must remain local. Preserve original bytes, input-version checks, conflict handling, result validation and durable recovery evidence.

A new format needs content-based detection, an implemented route, explicit losses and parameters, full output validation and real-engine tests. The UI must report unavailable engines accurately. Do not infer decoder input from the current extension.

Run the tests on disposable copies. Include cancellation, damaged input and conflict cases where relevant. Report untested operating systems, filesystems and codec variants explicitly.

Contributions are accepted under GPL-2.0-or-later, matching this repository. Third-party components keep their original notices and licenses.
