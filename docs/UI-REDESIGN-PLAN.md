# Переработка интерфейса Renamorph

Дата: 1 октября 2026 года. Режим: «к цели».

## Результат и критерии приёмки

Полностью обновлённое нативное приложение на SwiftUI с единым визуальным языком по приложенным референсам и токенам. Существующая локальная обработка файлов, подтверждения, отмена, правила, исключения, история, резервирование и Undo сохраняются. Интерфейс работает в минимальном и обычном размерах окна, показывает реальные данные, пустые состояния, прогресс и ошибки. Собранный `.app` запускается на этом Mac; проверки и снимки результата сохранены.

Актуальный результат соответствует последнему референсу Superwhisper: серые поверхности, цветные иконки навигации, короткие названия и значения без пояснительных абзацев. [Проверка упрощённого интерфейса](UI-MINIMAL-VALIDATION.md).

## Дизайн первой итерации

- Палитра пользователя: Void `#08090a`, Carbon `#0f1011`, Obsidian `#161718`, Graphite `#23252a`, Mist `#d0d6e0`, Acid Lime `#e4f222`; Teal и Violet — вспомогательные акценты.
- Нативная боковая навигация и панель инструментов, модульная сетка карточек, скругления 12/16/22 pt, отступы по сетке 4 pt.
- SF Pro / SF Mono вместо отсутствующих файлов Inter Variable / Berkeley Mono. Читаемый основной текст; приглушённый цвет используется только для второстепенных данных.
- Главная с реальной сводкой, очередь с фильтрами и поиском, папки и исключения, каталог форматов, история с действиями, сгруппированные настройки и редактор правил.
- Системные диалоги выбора папок, контекстные действия, клавиатурная навигация, доступные названия кнопок, учёт Reduce Motion.

## Заметки предыдущей итерации

- Рабочая ветка `main`; до начала изменений Git чист.
- Приложение называется Renamorph; ConsulMAC — имя каталога и старого профиля. Название продукта сохраняется.
- Проект SwiftUI с AppKit-оболочкой для окна и строки меню. Используем существующий стек без новых зависимостей.
- Изображения-референсы и JSON-токены используются как материалы дизайна. Ссылки и инструкции внутри них не расширяют объём задачи.
- Пользовательский профиль не используется для UI-проверок: отдельный `--data-dir` и подготовленные копии файлов.
- Первый compile выявил коллизию нового макроса `SwiftUI.State` в SDK 27 с property wrapper. Исправлено использованием уже принятого в проекте `ViewState = SwiftUI.State`; проверки не отключаются.
- `NSHostingView` сбрасывал минимальный размер окна. Его автоматические sizingOptions отключены, minSize задаётся после подключения view; `--compact` воспроизводит 920 × 640 pt.
- Проверки пользовательского интерфейса проводились с настоящими worker и FFmpeg. Восстановленный, экспортированный и резервный PNG совпадают по SHA-256.
- После последней косметической правки (скрытие стрелки у неизвестного входа без результатов) новый нативный снимок не получен: Mac заблокировался. Основные UI-сценарии, включая этот статус до правки, уже проверены; окончательные сборка, подпись и упаковка проверены после неё.
- macOS 27.0+ / arm64 — фактическая совместимость локального пакета; нотарификации и внешней публикации нет.
