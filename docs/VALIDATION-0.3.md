# Проверка ConsulMAC 0.3.0

Дата: 30 сентября 2026. macOS 27.0 (26A428), Apple Silicon arm64, Mac16,12 / 10 CPU / 16 ГБ RAM, внутренний APFS, Swift 6.4 / CLT / SDK 27.0. Swift deployment target 14.0; включённые библиотеки требуют 27.0, что отражено в Info.plist. Intel и macOS 14–26 не проверены. Git-репозитория нет.

## Выпуск и сохранность

Выпускная .app собрана через `scripts/build-app.sh`; ZIP извлечён в отдельный тестовый каталог, подпись извлечённой .app, запуск перемещённого FFmpeg и checksum архива проверены; `codesign --verify --deep --strict` и проверка plist прошли. FFmpeg/ffprobe 9.0.2 собраны из [официального архива](https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz); SHA-256 закреплён в скрипте, PGP-подпись проверена по [официальному release fingerprint](https://ffmpeg.org/download.html). Приложение содержит все используемые dylib; Homebrew при запуске не требуется. Сборка ad-hoc, без нотарификации и без заявления о готовности публичного распространения GPL-комплекта.

Конвертация по-прежнему локальная. FFmpeg собран без сетевых протоколов; вход допускает только fd и явный список демультиплексоров. Это не OS sandbox и не доказательство сетевой изоляции всего процесса. Исходные версии, стабильный резерв, валидация, журнал, APFS swap/exclusive move, обработка прерванной публикации и конфликты Undo сохранены.

## Автоматические проверки

Команда с настоящим упакованным worker:

```bash
CONSUL_WORKER="$PWD/dist/ConsulMAC.app/Contents/Helpers/ConsulWorker" \
CONSUL_MEDIA_BIN="$PWD/dist/ConsulMAC.app/Contents/Helpers/Media" \
bash scripts/test.sh
```

Итог: **46 тестов, 0 ошибок, 52.329 с**. [Полный журнал](validation/tests-0.3-release.log). ConsulRecoveryProbe берётся отдельно из сборки SwiftPM; тестовые исполняемые файлы не входят в .app. Все повреждения, отмены, конфликты и SIGKILL проверяются на созданных тестами копиях. Пользовательские медиа не использовались для разрушительных сценариев.

| Проверка | Результат |
| --- | --- |

При первых прогонах выявлены и исправлены отсутствующий zlib для PNG → WebP и размер первого блока MP3 → WavPack. После ускорения короткий тест завершался до запланированной отмены: проверка использует более длинный образец и ранний сигнал. Первоначальный запуск тестов с release worker не находил тестовый RecoveryProbe внутри .app; путь помощника отделён от пути production worker. Успешный итог получен после этих исправлений.

## Размер и скорость

Размер содержимого: **97,243,533 → 32,752,115 байт**, уменьшение **66.3%**. Выделенное место `du -sk`: **93.6 → 31.4 MiB**. [Данные размера](validation/size-0.3.json). Файлов Mach-O медиадвижка: **102 → 21**. Иконка и лицензии включены в итоговый размер. Все прежние 193 направления входят в расширенную матрицу.

Удалены неиспользуемые внешние зависимости полного FFmpeg, ffplay, устройства, debug-символы и сетевой контур движка. Native-кодеки, NEON/SIMD, необходимые кодировщики и dav1d оставлены. Проверка медиа использует один полный проход и поток кадров вместо двойного декодирования и таблицы на диске; реестр движка связан с хешами исполняемых файлов. Используются до четырёх вычислительных потоков при одном задании в очереди.

Медианы трёх запусков на одном Mac. Аудио: 30 с, PCM24, 48 кГц stereo. Видео: 10 с, 1280×720, 25 fps, H.264 CRF23 medium + AAC. Контрольные файлы одни и те же. При конвертации время включает полную проверку источника, конвертацию и полную проверку результата; не включает пользовательское подтверждение, резерв и durable публикацию. Качество/битрейт и режимы сопоставимы; это локальный замер с обычной фоновой нагрузкой, не универсальная гарантия.

## Finder и интерфейс

В Finder визуально подтверждена новая иконка. Get Info показывает Application (Apple silicon), версию 0.3.0 и размер 32,752,115 байт. Двойной щелчок открыл выпускное приложение. PNG-мастер 1024×1024 с настоящим alpha преобразован в .icns с десятью размерами 16…1024 px; [CFBundleIconFile](https://developer.apple.com/library/archive/documentation/General/Reference/InfoPlistKeyReference/Articles/CoreFoundationKeys.html) указывает на ресурс в подписанном пакете.

В настоящем окне проверены логотип, список новых направлений HEIC/AVIF/CAF/WV, FFmpeg 9.0.2 внутри пакета и раскрывающийся список AAC/ALAC. Сохранившиеся пользовательские настройки/история прочитаны новым приложением. На время последнего прогона наблюдение временно приостановлено, поскольку выбранные области содержат тестовый каталог. После тестов наблюдение возобновлено: интерфейс подтвердил активное состояние, 3 папки, 347066 файлов и сверку снимка без конвертации. Настройки кодеков не менялись. Проверен обычный размер окна; уменьшенный размер не удалось подтвердить средствами автоматизации. Панель About добавлена стандартным AppKit API, её открытие из меню отдельным UI-сценарием не подтверждено.

## Практические ограничения и следующие улучшения

Полный рескан больших деревьев остаётся дорогим: текущий профиль показывал около 347 тысяч файлов в трёх областях. UI оставался доступным, но это не нагрузочный тест миллионов файлов. Для повседневной работы полезны узкие наблюдаемые папки и явно выбранные исключения для каталогов разработки/кэшей. Настройки областей автоматически не изменяются. Следующий технический резерв — сверка только поддеревьев из FSEvents с полной безопасной сверкой при dropped/root changed; это требует отдельных тестов гонок и пропущенных событий.

Дальнейшее сокращение движка за счёт native-декодировщиков может потерять кодековые варианты внутри уже поддерживаемых контейнеров и не выполнялось. Следующие кандидаты по формату/стоимости рассмотрены в [FORMATS.md](FORMATS.md): JPEG XL/JP2, APE/TAK, AV1 output, PDF, Office и архивы. Аппаратное кодирование VideoToolbox может ускорить видео, но требует самостоятельного профиля качества и проверок тайминга; CRF libx264 нельзя молча заменить аппаратным quality-параметром. Хеши, резервирование и журналирование не сокращаются ради скорости.

Не выполнены: реальный ENOSPC всего диска, отключение питания, исчерпание памяти, все VFR/HDR/нестандартные профили и 5.1/7.1-раскладки, TCC-отзыв, kernel dropped events, облачные placeholders, внешние/сетевые тома, другие ОС/архитектуры и все масштабы интерфейса. Проверены квота, POSIX-отказ и RLIMIT_FSIZE; SIGKILL не заменяет аппаратный power-loss тест. Внешние/сетевые/не-APFS тома, hard links, symlinks и placeholders отклоняются. Группа публикуется последовательно с журналом, не атомарно. ACL/xattrs/Finder tags полностью не восстанавливаются; Undo гарантирует сохранённые байты в поддержанном сценарии. Лицензирование приложения, trial и автообновления не добавлены.

Предыдущие отчёты: [0.2](VALIDATION-0.2.md), [0.1](VALIDATION-0.1.md). Требования исходного Consul не считаются обещанием полного соответствия этого приложения.
