# Переработка интерфейса Renamorph — проверка результата

Дата: 1 октября 2026 года. [План работ](UI-REDESIGN-PLAN.md).

Этот отчёт фиксирует первую итерацию интерфейса. Последующее уточнение пользователя — серый стиль Superwhisper без пояснений — реализовано и проверено отдельно: [актуальный результат](UI-MINIMAL-VALIDATION.md).

## Что реализовано

Интерфейс приложения полностью переработан на SwiftUI. Существующая AppKit-оболочка сохранена для нативного окна, строки меню и системных диалогов. Новых зависимостей нет. `RenamorphCore`, worker, журнал, правила транзакций и формат сохранённых данных не изменены.

Из референсов использованы постоянная боковая навигация, модульные карточки, крупная типографика, скругления и нативные меню. Цвета взяты из прикреплённого JSON: Void, Carbon, Obsidian, Graphite, Mist, Acid Lime, Teal, Violet, Coral. Используются системные SF Pro / SF Mono: файлы Inter Variable и Berkeley Mono в проекте отсутствуют. Название Renamorph и существующая иконка сохранены.

Обновлены все основные экраны:

- **Обзор:** реальные счётчики, папки, начало работы и последняя операция.
- **Задания:** очередь, поиск, фильтры, подробности входа и веток, подтверждение, отклонение, отмена и публикация подготовленной группы.
- **Папки:** нативный выбор областей, исключения, защищённое хранилище и настройка новых файлов.
- **Форматы:** доступность worker и FFmpeg, 29 входных форматов, 264 доступных направления, категории, поиск и ограничения.
- **История:** завершённые и проблемные операции, восстановление оригинала и сохранение копии рядом.
- **Настройки:** общие параметры, отдельные правила пар, политика групп, резервы и ресурсы; редактор правил открывается нативным листом.

Последующие изменения касались только визуальной компоновки, подписей и размеров окна; ядро и worker не менялись, поэтому успешный набор не повторялся без нового риска.

## Нативная проверка

Проверялось реально запущенное приложение через системное дерево доступности и скриншоты, с отдельным профилем `test-artifacts/ui-redesign/profile`. Использовались только созданные для проверки файлы в `test-artifacts/ui-redesign/Watched`. Пользовательский профиль и реальные документы не изменялись.

| Сценарий | Подтверждённый результат |
| --- | --- |
| Пустой профиль, выбор папки системным диалогом | Начальное сканирование не создаёт заданий; выбранная папка появляется в интерфейсе |
| Исключение вложенной папки | Переименование `Excluded/Ignored.srt` в `.vtt` не создаёт задания |
| PNG → JPEG | Подтверждение из очереди создаёт настоящий JPEG; сигнатура результата `FF D8` |
| Детали и поиск задания | Показаны SHA-256, пути, параметры, движок и потери; поиск `sample` оставляет нужное задание |
| Сохранение оригинала рядом и Undo | Создана отдельная копия; восстановленный PNG, экспорт и резерв побайтово совпадают |
| SRT → VTT | После подтверждения создан текст с заголовком `WEBVTT`; операция появилась в истории |
| PNG → JPEG, WebP | При несогласованной политике результаты подготовлены, публикация отключена; после выбора политики и отмены ветки WebP опубликован только JPEG |
| Некорректный вход | Запись имеет статус «Не поддерживается» и диагностику; фильтр «Проблемы» оставляет эту запись |
| Отклонение задания | Запись `Decline.vtt` перешла в «Отменено», исчезла из очереди и осталась в истории; вход не изменён |
| Поиск без результатов | Показано пустое состояние; сброс фильтров возвращает список |
| Пауза и продолжение | Верхняя панель и пустая очередь отражают паузу; наблюдение возобновляется кнопкой |
| Создание правила HEIC → JPEG | Сохранено качество 85%; повтор той же пары блокируется |
| Смена источника правила на WAV | JPEG заменён совместимым MP3, показаны параметры медиа, кнопки редактора доступны; проверка отменена без сохранения |
| Частота аудио и лимит резерва | Нативное меню сохраняет 48 000 Гц; stepper сохраняет 3 ГБ |
| Повторный запуск | История, правило, папка, исключение и параметры сохранились |
| Каталог | Поиск `vtt` в категории субтитров оставляет VTT с доступным направлением SRT |
| Размеры окна | Проверены обычное окно 1180 × 818 pt и минимальное 920 × 640 pt; детали и длинные настройки прокручиваются |

SHA-256 исходного, восстановленного, экспортированного и резервного PNG:

```text
83bfd19d05cbf33fa6a93b384db464d843c253ccd3d16542dfefcaa676826e1c
```

[Доказательства состояния и файлов](validation/ui-redesign/ui-checks.json). После проверки в тестовом профиле 5 операций: два успешных преобразования, восстановленный оригинал, неподдерживаемый вход и отклонённое задание. Это контрольные данные, не демонстрационные ответы приложения.

Во время проверки исправлены сброс минимального размера окна со стороны `NSHostingView`, дублирующая системная панель инструментов, компоновка переключателя, русские даты и подписи счётчиков. В окончательной сборке дополнительно убрана стрелка направления у входа без доступных результатов.

После этой последней косметической правки новый снимок получить не удалось: Mac заблокировался. Нативные сценарии и статус неподдерживаемого входа проверены до неё; окончательные сборка, подпись, извлечение и сравнение пакета выполнены после неё. Остальные снимки соответствуют той же компоновке окончательного интерфейса.

## Передача

Готовые локальные артефакты:

- `dist/Renamorph.app` — приложение с включёнными движками.
- `dist/Renamorph-UI-Redesign-macOS-arm64.zip` — 15 517 330 байт, около 14.8 MiB.
- `dist/Renamorph-UI-Redesign-macOS-arm64.sha256` — контрольная сумма архива.

```text
4cd0219d6f3a6588a0162a5fb1ace9cd86c5260bcb8afd16bf727f39f20e3ef9
```

[Проверка пакета](validation/ui-redesign/package-checks.json). Архив извлечён и проверен; версия приложения 0.4.1 сохранена. Архивы прежних выпусков не перезаписаны. Коммит, push, публикация и внешняя отправка не выполнялись.

Для обычного использования откройте `dist/Renamorph.app` в Finder. Для повторения UI-проверки с изолированными данными:

```bash
open -n dist/Renamorph.app --args \
  --data-dir "$PWD/test-artifacts/ui-redesign/profile"
```

Для воспроизводимого минимального окна добавьте `--compact`. Два процесса не должны использовать одно хранилище одновременно.

Границы проверки: эта локальная сборка — arm64 / macOS 27.0+, с ad-hoc подписью, без нотарификации. Intel и macOS 14–26 не проверялись. Реальные настройки пользователя, сетевые и облачные тома не использовались. Названия элементов доступны в системном дереве; полностью озвученный сценарий VoiceOver и переключение системного Reduce Motion вручную не проверялись. Код учитывает Reduce Motion для анимаций.
