# Фактическая матрица 0.4.0

Реестр `Route` в `Sources/RenamorphCore/Models.swift` содержит 264 направления: 49 растровых, 213 аудио/видео и 2 текстовых. Это направления между контейнерами/форматами с указанными ниже ограничениями, а не обещание поддержки любого кодека или любого варианта файла. Одноимённый формат и совместимое расширение не требуют конвертации.

| Семейство | Вход по содержимому | Цели |
| --- | --- | --- |
| Статические изображения | JPEG, PNG, TIFF, HEIC/HEIF, BMP, WebP, GIF, AVIF | JPEG, PNG, TIFF, HEIC, BMP, WebP, AVIF |
| Аудио | MP3, WAV, FLAC, AIFF, M4A, AAC/ADTS, Ogg Vorbis, Ogg Opus, WMA/ASF, CAF, WavPack (.wv) | MP3, WAV, FLAC, AIFF, M4A, AAC/ADTS, Ogg Vorbis, Ogg Opus, CAF, WavPack |
| Видео | MP4, MOV, Matroska/MKV, WebM, AVI, MPEG-PS, WMV/ASF, MPEG-TS | MP4, MOV, MKV, WebM, AVI; также все аудиоцели для извлечения дорожки |
| Текстовые субтитры | SRT, WebVTT | SRT ↔ WebVTT |

WMV → AVI исключено: тест обнаружил изменение временных меток в AVI. Для WMV доступны остальные видеоцели и извлечение аудио.

Исключения из декартова произведения: одинаковые форматы; `.opus` → `.ogg` уже совместимо, поскольку Opus хранится в Ogg. В группе совместимая ветка получает побайтовую копию общего оригинала. Алиасы: jpg/jpeg/jpe, tif/tiff, heic/heif, aif/aiff/aifc, wav/wave, mp4/m4v, mpg/mpeg/vob, ts/mts/m2ts, vtt/webvtt. AAC/ALAC в аудио MP4 распознаётся как M4A и совместим с `.mp4`.

## Аудио и видео

Движок — отдельный RenamorphWorker и локальные FFmpeg/ffprobe 9.0.2. Готовая .app включает исполняемые файлы и их библиотеки. Исходный проект собирает компактный движок через `scripts/build-media.sh`; SIMD/NEON, native-кодеки, libx264, libvpx, libdav1d, libmp3lame, libopus, libvorbis и libwebp сохранены. Без движка аудио/видео и кодирование WebP недоступны.

Формат определяется демультиплексором по содержимому, EBML DocType/бренду ISO BMFF и составу потоков. Вход открывается через дескриптор `fd:`, не содержит расширения и допускает только протокол `fd` и явный список демультиплексоров. Плейлисты и ссылки на внешние ресурсы не поддерживаются. Для каждого входа и результата выполняется проверка контейнера и полное декодирование всех принятых потоков через ffprobe. Вывод уровня error отклоняет файл, даже при коде завершения 0; кадры и их временные метки обрабатываются потоком.

Ограничения: не более одной видеодорожки и одной аудиодорожки; 1–8 аудиоканалов; конечная положительная длительность до 24 часов. Обложки, вложения, дополнительные дорожки, субтитры внутри контейнера и потоки данных отклоняются. HDR PQ/HLG, прозрачное и чересстрочное видео отклоняются. Отсутствие аудиодорожки блокирует извлечение аудио. Неизвестный/отсутствующий декодер даёт ошибку до публикации.

| Цель | Кодек при перекодировании |
| --- | --- |
| MP3 | libmp3lame, mono/stereo |
| WAV | PCM signed 24-bit little endian |
| AIFF | PCM signed 24-bit big endian |
| FLAC | FLAC, до 24 бит |
| M4A | AAC или выбранный ALAC до 24 бит; MP4 audio |
| AAC | AAC / ADTS |
| CAF | PCM signed 24-bit little endian |
| WavPack (.wv) | Native WavPack, PCM до 24 бит |
| Ogg | Vorbis / libvorbis |
| Opus | Opus / libopus, 48 кГц |
| MP4, MOV, MKV | H.264 / libx264, YUV420 8 бит; аудио AAC |
| WebM | VP9 / libvpx-vp9, YUV420 8 бит; аудио Opus |
| AVI | MPEG-4 Part 2, q=3; аудио PCM 24-bit little endian |

Параметры: режим «перепаковка при совместимости», «перекодирование» или «только перепаковка»; 32–320 кбит/с для кодеков с потерями; частота источника / 44.1 / 48 кГц; CRF 16–35 (по умолчанию 23) для H.264/VP9. Для AVI CRF не применяется. При перепаковке битрейт/CRF не применяются; запрос изменения частоты требует перекодирования. Opus при перекодировании всегда 48 кГц. Сведения и фактическая операция сохраняются в истории.

Перепаковка разрешается явно заданной таблицей совместимости кодеков в `MediaPlan`: например H.264/AAC из MOV в MP4 или MKV; VP8/VP9/AV1 и Opus/Vorbis между совместимыми WebM/MKV. В режиме «только перепаковка» несовместимые потоки дают отказ. Выбор не основан на длине цепочки: маршруты прямые. Перепаковка сохраняет сжатые потоки, но **теги и главы не переносятся**. Перекодирование в AAC/MP3/Vorbis/Opus/H.264/VP9/MPEG-4 может снижать качество. WAV/FLAC из MP3 не восстанавливают утраченную информацию; 24-битный выход PCM/FLAC/WavPack/ALAC может уменьшать исходную разрядность. ALAC и WavPack сохраняют подготовленный PCM без потерь, но не отменяют предшествующее декодирование lossy-источника, изменение частоты или разрядности. Автоматического сведения числа каналов нет.

Проверка результата: контейнер, успешное полное декодирование, длительность (допуск 250 мс для задержки/дополнения кодеков), набор и кодеки потоков, частота и каналы аудио; геометрия, ориентация, пропорции пикселя и точное число декодированных кадров видео. Сверяется SHA-256 последовательности временных меток всех декодированных видеокадров относительно первого кадра, округлённых до миллисекунд. Контейнерная средняя частота используется только в описании: короткие контейнеры могут по-разному учитывать крайние временные метки. Поток описаний декодированных аудио- и видеокадров ограничен 512 МБ, строка — 32 КБ. В памяти хранится только текущая порция, таблица на диск не записывается; больший вход безопасно отклоняется. Недостающие PTS вычисляются FFmpeg с `+genpts` одинаково при анализе и преобразовании. В перекодировании используется сохранение временных меток без принудительного удвоения/удаления кадров. Это не доказательство идеальной синхронизации для любого повреждённого/VFR-файла; неподходящий результат не публикуется.

## Изображения

Сигнатура + согласованный ImageIO UTI + полное декодирование; ровно один кадр. Анимации, включая GIF/WebP, и многостраничный TIFF отклоняются. Кодирование JPEG/PNG/TIFF/HEIC/BMP/AVIF — ImageIO. Доступность кодировщиков и декодировщиков проверяется в текущей ОС. Бренды ftyp проверяются включая compatible brands: AVIF с основным mif1 не считается HEIC. WebP — libwebp в режиме lossless из нормализованного PNG.

Преобразование нормализует ориентацию, цвет в sRGB и глубину до 8 бит. Исходные EXIF/GPS и произвольные метаданные не копируются. JPEG/HEIC/AVIF с потерями; настройка качества применяется к ним. JPEG/BMP при наличии альфы требуют явного белого фона либо дают отказ. Остальные цели сохраняют наличие альфы. «WebP lossless» относится к уже нормализованному растру, а не ко всем свойствам исходного HEIC/TIFF. Проверяются формат, завершённое декодирование, число кадров, размеры, ориентация и альфа.

## Субтитры

Строгий UTF-8 SRT/WebVTT: текст, интервалы времени и переносы строк. SRT требует последовательных числовых номеров, WebVTT — простой заголовок. Оформление, HTML/ASS-разметка, entities, идентификаторы WebVTT, NOTE/STYLE/REGION и позиционирование отклоняются вместо молчаливой потери. Выход повторно разбирается; сверяются количество реплик и SHA-256 канонического текста с миллисекундными тайм-кодами. Внешние ресурсы не читаются. Размер до 16 МБ, до 100 000 реплик.

## Пока не реализовано

Кодирование GIF/WMA/WMV/MPEG-PS/MPEG-TS; анимации; PDF/Office; архивы; электронные книги/почта; JSON/YAML/XML и таблицы; шрифты и 3D. Добавление контейнера в список не заменяет движок и проверку направления. Проверки текущего набора перечислены в `VALIDATION.md`.
