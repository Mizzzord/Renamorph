# Renamorph — интерфейс без пояснений

Дата: 1 октября 2026 года. [План](UI-REDESIGN-PLAN.md), [руководство](USER_GUIDE.ru.md).

Отчёт фиксирует локальную проверку интерфейса до повышения версии пакета с 0.4.1 до 0.4.2. Упаковка ZIP/DMG и запуск версии 0.4.2 проверены отдельно: [выпуск 0.4.2](RELEASE-0.4.2.md).

## Результат

Последний референс Superwhisper заменил прежнее направление с лаймовым акцентом. Все основные экраны и редактор правил приведены к спокойному серому стилю: цветные иконки боковой панели, серое выделение, компактная верхняя панель, одна строка счётчиков, простые действия и списки. Удалены пояснения, слоганы, информационные карточки, подзаголовки и обычные служебные сообщения. Остались названия, значения, действия и реальные ошибки. Детали операции показывают пути, SHA-256, резерв и параметры без пояснительных абзацев.

Изменены только SwiftUI-представления и оболочка приложения: `DesignSystem.swift`, `MainView.swift`, `OverviewView.swift`, `JobsView.swift`, `FoldersView.swift`, `FormatsView.swift`, `SettingsView.swift`, `main.swift`. Ядро, worker, журнал, схема хранения, конвертация и резервирование не изменены. Зависимости не добавлялись.

## Проверка в приложении

Использованы отдельный профиль `test-artifacts/ui-minimal/profile` и созданные для проверки файлы `test-artifacts/ui-minimal/Watched`. Приложение запущено из готовой `.app`; действия выполнены через нативный интерфейс, состояние проверено по файлам и дереву доступности. Пользовательский профиль не использовался.

| Сценарий | Подтверждённый результат |
| --- | --- |
| Пустой профиль и системный выбор папки | Начальное сканирование не создало заданий; папка появилась в списке |
| PNG → JPEG | Подтверждение в очереди создало JPEG с сигнатурой `FF D8` |
| SRT → WebVTT | Подтверждение создало файл с заголовком `WEBVTT` |
| Некорректный вход | Реальный статус «Не поддерживается» и ошибка остались видимыми; фильтр проблем показывает эту операцию |
| Сохранение оригинала рядом и Undo | Резерв, экспорт и восстановленный PNG совпали с оригиналом по SHA-256 |
| Правило HEIC → JPEG | В редакторе сохранено качество 85%; правило сохранилось после перезапуска |
| Дубликат правила | Показана ошибка «Правило уже существует», добавление отключено; Escape закрыл редактор |
| Поиск без результатов | Короткое пустое состояние; «Сбросить» возвращает каталог |
| Настройки хранения | Нативный stepper изменил лимит с 2 до 3 ГБ; значение сохранено в профиле |
| Пауза и продолжение | Кнопка меняется; наблюдение возобновилось без постоянного пояснительного текста |
| Боковая панель | Скрытие и повторное открытие работают |
| Минимальный размер | Настройки хранения и правила помещаются; длинные списки прокручиваются; пустая очередь показывает только «Нет заданий» |
