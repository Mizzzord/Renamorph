# Проверка ConsulMAC 0.2.0

Дата: 17 сентября 2026. Среда: macOS 27.0 (26A428), Apple Silicon arm64, внутренний APFS, Swift 6.4 / Command Line Tools / SDK 27.0. Git-репозитория нет. Проверки используют сгенерированные данные в `test-artifacts`; пользовательские медиа не изменялись.

## Автоматические проверки

Команда: `./scripts/test.sh`. Итог: **42 теста, 0 ошибок, 126,652 с**. После уточнения текста диагностики лимита отдельно повторён тест ограничения выхода/отмены: **1 тест, 0 ошибок, 3,883 с** ([журнал](validation/output-limit-0.2.log)). После итоговой правки пояснений параметров выполнена новая release-сборка; алгоритмы конвертации не менялись. Полный журнал текущей сборки: [tests-0.2.log](validation/tests-0.2.log). Проверки используют настоящие процессы ConsulWorker, FFmpeg/ffprobe, ImageIO и файловые операции APFS; это не моки кодеков.

Матрица использует маленькие файлы: 32×24 для растров; 64×48, 25 fps, обычно 1 секунда для видео; синус 48 кГц stereo. Это подтверждает каждый реализованный маршрут, но не каждый профиль/кодек/возможное повреждение контейнера.

При проверке были найдены и исправлены ошибки: совместимость Ogg Opus, сравнение ненадёжной средней частоты контейнера вместо временных меток кадров, генерация отсутствующих PTS MPEG-PS и дополнительная задержка MP3 в выходном AVI. AVI теперь использует PCM 24-bit. **WMV → AVI исключено**: контроль временных меток обнаружил изменение первых интервалов, и проверка не была ослаблена ради объявления маршрута. Начальный запуск FFmpeg full при проверке WebP превысил тестовый тайм-аут; последующие прогоны растров прошли. Точная причина этой разовой задержки не установлена.

## Выпускная локальная сборка

Команда: `./scripts/build-app.sh`; журнал [release-build-0.2.log](validation/release-build-0.2.log). FFmpeg/ffprobe 9.0.1, Homebrew ffmpeg-full 9.0.1_1. Скрипт упаковывает 102 Mach-O, переписывает несистемные зависимости на относительные ссылки и выполняет ad-hoc codesign с проверкой всей .app. Версии/библиотеки/лицензии/хеши находятся в `Contents/Resources/ThirdParty`.

Текущий комплект библиотек требует **macOS 27.0**; готовая .app объявляет этот минимум. Обещания работы этого комплекта на macOS 14–26 или Intel нет. Исходники Swift используют deployment target 14.0, что само по себе не делает сторонние библиотеки совместимыми с этой ОС. Публичная подпись, notarization и комплект исходников сторонних библиотек для публичного распространения не готовились.

## Проверка интерфейса и реального .app

В отдельном профиле `test-artifacts/media-ui` через native UI выполнены:

1. Файловое переименование FLAC под `.mp3`, распознавание FLAC по содержимому, просмотр эффективных параметров, подтверждение, состояния выполнения и успеха. Независимый `file` определил настоящий MP3, 192 кбит/с, 48 кГц, stereo.
2. Undo кнопкой приложения: исходный FLAC вернулся под прежним именем с совпадением SHA-256; MP3 исчез из пользовательского пути.
3. MOV под `.mp4`: интерфейс показал перепаковку H.264/AAC. Результат опубликован; `ffmpeg -map 0 -c copy -f streamhash` дал совпадающие SHA-256 обоих сжатых потоков для резерва и MP4 (свидетельство в `test-artifacts/media-ui/remux-streamhash.txt`).
4. В настройках создано правило FLAC → MP3 «Автоматически». Повторное реальное переименование завершилось без подтверждения, история сохранила источник эффективного правила.
5. Переименование SRT под `.vtt` создало ожидающее задание с фактическим SRT. Round-trip преобразование субтитров проверено автоматическим тестом; это UI-задание оставлено ожидающим.
6. Итоговая .app запущена с обычным хранилищем. Визуально проверен раздел форматов со списками аудио, видео и субтитров; встроенный FFmpeg найден внутри .app. Окно оставлено открытым в разделе «Форматы». Обычный профиль пользователя не получил тестовых правил или папок.

Повторный запуск с тестовым `--data-dir` внутри Documents после очередной ad-hoc переподписи остановился на системном `open` каталога во время синхронизации состояния. Sample процесса и журналы TCC показали проверку доступа Documents. Инструмент не разрешает управление системным UserNotificationCenter, поэтому этот повторный UI-сценарий не засчитан как успешный. Процесс тестового профиля завершён; обычный запуск с Application Support прошёл. История и настройки тестового профиля остались на диске, а их декодирование при запуске дошло до сохранения состояния. В коде не отключались проверки доступа и не запрашивался Full Disk Access.

## Ограничения доказательств

- Физический диск не заполнялся до ENOSPC. Проверены квота, POSIX-отказ и RLIMIT_FSIZE на специально созданном медиафайле. SIGKILL не является тестом отключения питания или аппаратного кэша.
- Только внутренний APFS. Внешние/сетевые/облачные тома, HFS+/FAT/exFAT не поддерживаются; реальные placeholders не создавались.
- HDR, интерлейс, alpha-video, многодорожечность, обложки и вложения отклоняются. Ограниченные тесты не доказывают распознавание каждой нестандартной разметки HDR/alpha.
- Не проверена широкая библиотека реальных VFR, нестандартных профилей, повреждённых длинных роликов, всех раскладок 5.1/7.1, всех свойств цветопередачи и субъективного качества. WAV/FLAC из lossy-источника не восстанавливают качество.
- Прогресс отражает этапы, точный процент кодека не реализован. Распознавание/полная проверка длинного видео может занять заметное время; доступна отмена и настраиваемый тайм-аут.
- Нет проверки сети packet capture или OS sandbox. Путь запуска ограничивает входной протокол `fd` и демультиплексоры; сетевые возможности библиотеки FFmpeg не используются. Это не утверждение сетевой изоляции средствами ОС.
- TCC-отзыв, kernel dropped events, миллионы наблюдаемых файлов, исчерпание памяти, все гонки системных вызовов и все масштабы экрана отдельно не воспроизводились.
- Не заявлено полное сохранение ACL/xattrs/Finder tags и метаданных медиа. Исходные байты и резерв проверяются отдельно. Undo не перезаписывает изменённый результат.
- Публикация группы последовательна с журналом, не атомарна. Политика группы по умолчанию требует явного выбора, автоматический откат/продолжение частичной публикации отсутствуют. Лицензирование приложения, trial и автообновления не добавлены.

Отчёт прошлой версии с исходными сценариями интерфейса: [VALIDATION-0.1.md](VALIDATION-0.1.md).
