# Renamorph 0.4.2 — проверка выпуска

Дата: 1 октября 2026 года. [GitHub Release](https://github.com/Mizzzord/Renamorph/releases/tag/v0.4.2), [руководство в README](../README.md#руководство-по-использованию).

Выпуск содержит переработанные SwiftUI-экраны с серыми поверхностями и короткими подписями, руководство по установке и использованию, нативный снимок приложения и обновлённые ссылки загрузки. Версия приложения — 0.4.2, номер сборки — 6. Ядро, worker, схема журнала и параметры конвертации сохранены.

## Проверки перед публикацией

| Проверка | Результат |
| --- | --- |
| `scripts/build-app.sh` | Успешно, 18.76 с; 21 Mach-O и FFmpeg 9.0.2 |
| Нативный запуск | В окне отображается Renamorph 0.4.2; реальная история и сохранённые настройки читаются из отдельного тестового профиля |
| Сравнение с проверенной сборкой интерфейса | Код основного исполняемого файла вне блока подписи совпадает; все остальные исполняемые файлы и ресурсы совпадают по SHA-256 |
| Тесты этого кода | 47 тестов прошли за 34.096 с при проверке интерфейса; после изменения версии и подписи набор повторно не запускался |
| `scripts/package-release.sh 0.4.2` | Финальный запуск завершён успешно: ZIP, DMG, исходники движка и контрольные суммы |
| ZIP и смонтированный DMG | Все 65 файлов приложения совпадают с исходной `.app` по SHA-256 |
| Подписи ZIP/DMG | `codesign --verify --deep --strict` успешно |
| Целостность | ZIP и DMG проверены, `Info.plist` корректен, контрольные суммы совпадают |
| Исходники движка | Все 10 архивов проверены по SHA-256; совпадают с прежними точными версиями компонентов |
| Рецепт упаковки исходников | В архиве лежит текущий `scripts/package-sources.py` из репозитория |
| README | Локальные ссылки и блоки кода проверены; снимок снят с настоящего приложения |

В первом запуске упаковки повторный запрос точной ревизии x264 завис на сервере upstream. Упаковщик исправлен: он проверяет наличие закреплённого git-объекта в кэше, использует его при наличии, иначе загружает с ограничением времени. Идентичность ревизии и хеш итогового архива проверяются. Финальный запуск штатного скрипта выполнен после исправления; все хеши upstream-архивов совпали с предыдущим выпуском. Первый комплект пакетов сохранён в отдельном локальном тестовом каталоге.

[Проверки и хеши](validation/release-0.4.2/checks.json), [сборка](validation/release-0.4.2/build.log), [упаковка](validation/release-0.4.2/package.log), [47 тестов и нативные сценарии](UI-MINIMAL-VALIDATION.md). В журналах локальные пути заменены на `$PROJECT` и `$HOME`.
